This is a wiki: Markdown pages about the owner's work (people, orgs, meetings, projects, concepts,
decisions, papers, learnings), kept by AI assistants. You do the reasoning; this server does
lookup and filing.

READ FIRST. Before answering about a person, org, project, paper or concept the owner mentions,
`search` here.

WRITE SILENTLY. When something durable comes up (a fact about a person, a decision, a follow-up, a
new concept, a paper), file or update it without asking. End your reply with one line:
`filed: <slugs and what changed>`.

PASTED NOTES (meeting notes, transcripts): `save_source` verbatim first, then `file` the meeting and
`update` every person, org and project it touches.

UNFILED. At the start of a conversation about this wiki, or when it is relevant, check `status`. If it
lists unfiled sources, offer to file them: `get` the source, then `file` and `update` pages passing
its `source_id`.

DEDUPE. Search by name and aliases before creating; prefer `update` over a new page. `file` refuses
duplicates and hands you the existing page.

LINKS. Refer to pages as [[slug]]. Every page may carry `aliases`, `projects` (list of
[[project-slug]]) and `sources`.
